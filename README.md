## 🛠️ Curriculum & Core Modules
Based on the official IIT DU course guidelines, this repository tracks progress across the following modules:

1. **Python Core Programming**
   * Foundational syntax, data structures (Lists, Tuples, Dictionaries), and control flows.
   * Object-Oriented Programming (OOP) concepts in Python.

2. **AI-Assisted Development & Environment Setup**
   * Setting up modern interactive environments using Jupyter Notebook.
   * Leveraging AI-assisted development tools (such as **Cursor** and AI pairs) to accelerate coding and debugging workflows.

3. **Data Manipulation & Wrangling**
   * Scientific computing using **NumPy** (Arrays, Vectorization, Matrix arithmetic).
   * Data analysis using **Pandas** (DataFrames, Series, handling missing data, filtering, and aggregation).

4. **Exploratory Data Analysis (EDA) & Visualization**
   * Creating publication-quality static graphics using **Matplotlib**.
   * Advanced statistical data visualization using **Seaborn**.

5. **Statistical Analysis**
   * Practical application of basic statistical methods, data cleaning strategies, and preparation for structured data tasks.

## 🚀 Getting Started Locally

### 1. Prerequisites
Make sure you have Python 3.x installed. You can install all necessary tools and libraries using pip:
```bash
pip install numpy pandas matplotlib seaborn jupyter
```

### 2. Clone the Repository
```bash
git clone https://github.com
cd YOUR_REPO_NAME
```

### 3. Open the Labs
Run the following command to open the practical exercises in your browser:
```bash
jupyter notebook
```
